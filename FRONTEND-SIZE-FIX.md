# Frontend size fix v2

The desktop/laptop layout was adjusted to match the supplied WhatsApp Desktop reference more closely.

Changes are limited to frontend sizing/layout CSS:
- wider Chats/contact panel (roughly WhatsApp Desktop proportions)
- stable 64px desktop navigation rail
- larger, clearer contact names and preview text
- consistent avatar, header, search and composer sizes
- media/message sizing kept balanced in the chat area
- separate narrow-laptop breakpoint retained
- mobile layout remains unchanged

Backend, login, database, message sending and API logic were not changed.
